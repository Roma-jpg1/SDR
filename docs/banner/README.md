# Баннер SDR

Исходник анимации в шапке главного README. Земля, спутники и текстуры построены в Three.js; движение связано со временем Hyperframes. Модели и изображения извне не загружаются.

GIF: 1200 × 400, 25 кадров/с, бесшовный цикл 8 секунд. Орбиты замыкаются точно; положение спутников, следы и радиоволна вычисляются для каждого кадра независимо.

Для пересборки нужны Node.js 22+ и FFmpeg:

```sh
cd docs/banner
npm ci
npm run check
npm run gif
```

Результат записывается в `docs/images/satellite-orbit.gif`. Для просмотра композиции: `npm run dev`.

`index.html` задаёт оформление и таймлайн, `scene.js` — геометрию и движение. Адаптер сцены основан на примере `three-orbiting-cards` из каталога Hyperframes.
